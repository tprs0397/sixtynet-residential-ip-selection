## 洛杉矶住宅 IP 到底算不算“独立 IP”

算，但要分清三组容易混的概念。

**机房 IP 和住宅 IP 的区别在 ASN。** TikTok 拿到你的连接，第一步是查这个 IP 属于哪一类网络。数据中心 IP 的 ASN 一眼就是商用出口，平台对这类 IP 的容忍度低。住宅 IP 走的是本地 ISP 的家庭宽带网段，在风控眼里更接近真实用户。这也是 SixtyNet 这类产品存在的全部理由：卖的不是服务器，是那个 IP 的出身。

**原生 IP 和家宽 IP 不是一回事。** 原生指的是 IP 注册地和服务器实际所在国一致，美国 IP 确实注册在美国。家宽指的是这个 IP 从当地 ISP 的家庭宽带里出来。原生 IP 可能仍然是机房段，只是归属地对了。买之前要看清楚商家标注的是“原生 IPv4”还是“原生家宽 IPv4”，这两个词的差价能有几倍。SixtyNet 的住宅系列标的是 ISP Residential，属于后者。

**双 ISP 是加分项，SixtyNet 的默认配置是单 ISP。** 双 ISP 指这个 IP 同时在两个运营商名下注册，网络路径和信誉度都更好。有优惠码站写得很明确：SixtyNet 住宅系列默认为单 ISP，可以在配置项里选 Cox Communications 或 Wave Broadband 做双 ISP，需要额外加 $5 一个月。官网宣传语写的是 Dual ISP Residential，下单时务必在配置页确认这一项有没有勾上，别默认以为价格里已经包含。

独享这一项 SixtyNet 没有含糊，每台机器自带一个独立 IPv4，不和别人共用。

至于“一机一号一 IP”，这是运营纪律，不是产品功能。一个账号对应一台设备或一个隔离环境，绑一个长期不变的 IP，三者不交叉。买到了干净 IP，多个号轮流登同一台机器，风控照样找上来。

## 直播场景：不要只看端口标称的 10Gbps

SixtyNet 四个套餐都写 10Gbps 带宽。这个数字对直播没多少参考价值，它是端口速率，不是你能持续跑满的上行。

实际要盯三件事：

**持续上行。** 1080P 直播推流大概需要稳定 6–10Mbps 上行，4K 更高。行业里另一个常被引用的下限是上行至少 5Mbps、高清 10Mbps 以上。10Gbps 端口远高于这个门槛，所以在这个价位上，带宽不是瓶颈，链路质量才是。

**回程抖动和丢包。** 直播画面卡顿，多数时候不是上行不够，是回程抖。判断标准可以照这个基线：p50 延迟低于 80ms、抖动低于 20ms、丢包率低于 0.5%。CN2 GIA 在晚高峰的表现通常比普通 163 线路稳，但这是线路类型的一般规律，不代表任何一台机器的实测结果，买回来自己 ping 一段晚高峰时段的曲线最靠谱。

**流量怎么算。** 住宅系列标的是 5T 到 40T。需要注意这是出方向流量还是双向计费，资料里没写清。直播上行消耗大，如果按双向计费，5T 在天天开播的情况下撑不到一个月。下单前问客服确认计费方向，比事后算账有用。

直播对 IP 的要求比短视频更苛刻，这是共识。短视频偶尔卡一下不影响发布，直播断流是当场掉粉。所以真要做直播，MICRO 起步更稳妥，多出来的 5T 流量和 4 核余量是给推流软件和 obs 留的缓冲。

## 常见问题

**独立 IP 和共享 IP 差在哪？**
共享 IP 一个地址被几十上百人用，其中一个人违规，整段 IP 进黑名单，你跟着受牵连。独立 IP 只有你一个人用，出问题的概率取决于你自己的操作。低价“独享”未必真独享，买回来用 IP 检测工具查一下这个地址被多少账号用过。

**原生 IP 是不是就是家宽 IP？**
不是。原生只说明 IP 注册地和服务器所在国一致，它可能仍然属于机房段。家宽 IP 是从当地 ISP 家庭宽带出来的，风控信任度更高。买之前认准商家页面上写的是哪一个。

**TikTok 直播要多少带宽？**
上行至少 5Mbps，1080P 高清建议 10Mbps 以上。比带宽数字更重要的是不丢包、不断流、回程抖动小。端口标 10Gbps 不等于你能稳定跑满，要看商家承诺的持续上行。

**IP 会不会中途变？**
SixtyNet 住宅系列是静态 IP，不会自动轮换。动态 IP 适合刷视频和广告测试，养号必须固定，这点没有商量余地。真正要注意的是别自己换节点，有些人为了提速来回切线路，IP 一跳，前面的养号全白做。

**能不能退款？**
3 天内、流量不超过 5GB、扣手续费、原路退回。超过任何一条都不行。

**月付还是年付？**
第一台机器月付。跑满一个月，看 IP 风险评分、晚高峰延迟、账号播放数据，都正常再考虑年付。年付叠加折扣一年省二三十美元，不值得为这个把试错空间压掉。

**注册收不到验证码怎么办？**
先解决注册再谈买。有测评提到 +86 号码收不到验证码，可以试试其他地区的号码，或者先开工单问清楚支持哪些验证方式。
